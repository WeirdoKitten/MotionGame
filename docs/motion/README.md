# Family Adventure — Motion Games Assets

Asset reference sheets for the 3 Motion Games.

## Game 01 — Star Catch
- Star assets: normal, big, high, bonus
- Catch VFX: burst, sparkle, ring pulse, trail, clap burst
- Body target indicators: hand, knee, foot, jump, clap
- Calibration / position guide (~1.5 m)
- UI, audio icon and reference gameplay screen
- Instruction / how-to-play boards

## Game 02 — Follow The Line
- Glowing line path assets and themes
- Body-part instruction icons: hands, knees, feet, jump
- Calibration / position guide (~1.5 m)
- VFX line effects
- UI, audio icons and reference gameplay screen
- Environment / modular props

## Game 03 — Avoid The Rock
- Rock obstacle variants: normal, left, right, high, low, large, fast, special, stack
- Obstacle VFX: spawn, move trail, dust, impact/miss, disappear, warning
- Player action icons: left, right, jump, duck, center
- Feedback/UI/audio references
- Day/night environment and modular props
- Reference gameplay screens

## Game 04 — Jump And Duck
- Obstacle variants: low obstacle (logs/water flow) for jumping, high obstacle (hanging branch/bees) for ducking/squatting
- Lower-body kinematics tracking: Hip center, knee flexion angle, and ankle clearance
- Jitter reduction via adaptive filtering (One Euro Filter)
- Action recognition via Finite State Machine (FSM)
- Calibration & baseline posture capture (~1.5 m)
- UI and reference gameplay screens

## Important
These are visual asset/concept reference sheets. Runtime Unity assets (individual PNG sprites, 3D prefabs, materials, VFX graphs, audio files, etc.) still need to be exported/created from these references according to the corresponding GDD/Mechanics MD files.
